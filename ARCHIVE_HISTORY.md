# Historical research archive (archive/phase10-experiments-20261105)

This is a **preservation-only branch**. Its first archive commit has multiple parents to keep the full commit histories of experimental branches reachable while leaving the working tree based on the then-current `main`.

This archive **does not merge experimental features into the deployed product**. Its checked-out tree resembles `main`; to inspect older source, open the relevant parent commit or use `git show <commit-sha>:<path>`.

Included histories:
- isometric Match Director branch
- knockout baseline branch
- Pokémon sprite tests
- Watch→Sim public browser tests
- retired GitHub Pages distribution

Do not use this branch for production deployment or normal development. It exists so redundant experiment branch names can eventually be deleted without losing their commits.

**Branches are not yet deleted**; cleaning refs requires the GitHub UI or a GitHub CLI with write permission.
